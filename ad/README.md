# 시그널그룹 광고 페이지 운영 폴더

이 폴더는 회사에서 사용하는 광고·리쿠르팅·상담 랜딩페이지의 운영 영역입니다.

`새홈페이지_공통접수_기준본`은 인슈런스 매니저용 기능이므로 이 폴더와 분리하여 관리합니다.

## 운영 원칙

1. 실제 배포 페이지와 페이지가 사용하는 이미지·CSS·JS만 GitHub에 올립니다.
2. Telegram Bot Token, Chat ID, 담당자 이메일을 HTML/JS에 직접 넣지 않습니다.
3. 모든 신청 폼은 중앙 Apps Script 주소로 전송합니다.
4. 담당자는 페이지에 고정된 `source_code`로 구분합니다.
5. 기존 광고 URL이 확인되기 전에는 기존 폴더명과 `index.html`을 이동하거나 삭제하지 않습니다.
6. `복사본`, `.bak`, 검수 캡처, 편집 원본은 배포 대상에서 제외합니다.

## 정리 단계

- 1단계: 기존 파일·URL 보존, 보안 정보 제거
- 2단계: 실제 운영 페이지에 중앙 접수와 출처코드 적용
- 3단계: 페이지별 접수 시험
- 4단계: 미사용 복사본·검수 자료를 저장소 밖으로 이동
- 5단계: 검증된 파일만 GitHub에 반영
